# Claude Desktop

## Sessions

| Keys | Action |
|---|---|
| `Ctrl+N` | New session *(built-in)* |
| `Ctrl+W` | Close the session *(built-in)* |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Cycle through sessions *(built-in)* |
| `Ctrl+Shift+[` / `Ctrl+Shift+]` | Previous / next session *(built-in)* |
| `Alt+Click` | Open the session side by side *(built-in)* |
| `Ctrl+Click` | Open the session in its own window *(built-in)* |
| `Ctrl+Alt+W` | Take the focused session out of split view *(built-in)* |

## Prompt

| Keys | Action |
|---|---|
| `Esc` | Stop Claude's response *(built-in)* |
| `Tab` / `Right` | Accept the suggested prompt *(built-in)* |
| `Ctrl+;` | Open a side chat *(built-in)* |
| `Ctrl+O` | Cycle transcript view modes *(built-in)* |
| `Ctrl+Enter` | Submit all diff comments *(built-in)* |

## Panes

| Keys | Action |
|---|---|
| `Ctrl+Shift+D` | Toggle the diff pane *(built-in)* |
| `Ctrl+Shift+B` | Toggle the browser pane *(built-in)* |
| `Ctrl+Shift+S` | Pick an element in the browser *(built-in)* |
| ``Ctrl+` `` | Toggle the terminal *(built-in)* |
| `Ctrl+\` | Close the focused pane *(built-in)* |

## Menus

| Keys | Action |
|---|---|
| `Ctrl+Shift+M` | Permission mode *(built-in)* |
| `Ctrl+Shift+I` | Model *(built-in)* |
| `Ctrl+Shift+E` | Effort *(built-in)* |
| `1`–`9` | Pick an item in the open menu *(built-in)* |
| `Ctrl+Alt+1`–`9` | Choose an environment, on the new session screen *(built-in)* |
| `Ctrl+Alt+0` | New environment *(built-in)* |
| `Ctrl+/` | List every shortcut *(built-in)* |
