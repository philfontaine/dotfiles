# Terminal

## Tabs

| Keys | Action |
|---|---|
| `Ctrl+T` | Duplicate the tab |
| `Ctrl+H` / `Ctrl+L` | Previous / next tab |
| `F2` | Rename the tab |
| `Ctrl+Shift+Space` | New tab menu: Terminal, Neovim, Launcher, Cheatsheet *(built-in)* |

## Panes

| Keys | Action |
|---|---|
| `Alt+Shift+Plus` | Split right |
| `Alt+Shift+Minus` | Split down |
| `Alt+Shift+H/J/K/L` | Focus the pane left / down / up / right |
| `Ctrl+Alt+Shift+H/J/K/L` | Resize the pane left / down / up / right |
| `Ctrl+W` | Close the pane |

## Window

| Keys | Action |
|---|---|
| `Ctrl+Shift+P` | Command palette *(built-in)* |
| `Ctrl+Shift+F` | Find *(built-in)* |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | Zoom in / out / reset *(built-in)* |
| `Ctrl+,` | Settings *(built-in)* |
